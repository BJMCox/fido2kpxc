Unlock KeePassXC with a FIDO2 security key

fido2kpxc keeps your KeePassXC database passwords in a vault that only your security keys can open. When KeePassXC shows its unlock screen, fido2kpxc asks for the key's PIN and a touch, then fills in the password and unlocks the database. It never uses the clipboard unless you turn on "Copy Password".

It works with any FIDO2 key that supports hmac-secret and has a PIN, for example YubiKey, Token2, or Google Titan.

This package installs /Applications/fido2kpxc.app and nothing else. It runs no scripts and writes no settings. It needs macOS 13 or later on a Mac with Apple silicon.
