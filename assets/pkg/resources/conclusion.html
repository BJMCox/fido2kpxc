Next steps

  1. Open fido2kpxc from Applications. The app is self-signed, so the first time, right-click it and choose Open. A key icon appears in the menu bar.
  2. Choose "Settings…" in the menu and set the vault folder.
  3. Choose "Set Up…", enter the database password and the key's PIN, and touch the key twice.
  4. Choose "Grant Accessibility…" and allow fido2kpxc in System Settings.

The README at github.com/BJMCox/fido2kpxc covers backup keys, several databases, and the terminal commands.
